# Privacy Policy

**Last Updated:** October 23, 2026

This Privacy Policy explains how our Discord Bot ("the Bot") handles user data. By using the Bot or keeping it in your Discord server, you agree to the collection and use of data as outlined in this policy.

## 1. Information We Collect
We only collect the minimum data necessary to provide moderation and gaming functionalities:
* **Discord IDs:** User IDs, Server (Guild) IDs, and Channel IDs.
* **Moderation Logs:** Server-configured settings, warning records, and moderation history.
* **Game & Activity Data:** Mini-game statistics, scores, and economy balances stored per server/user.

We **do not** store passwords, personal real-world identity details, or sensitive financial information.

## 2. How We Use Data
The collected data is strictly used to:
* Store server settings (e.g., custom prefix, moderation rules).
* Track leaderboards, game progress, and user stats.
* Ensure smooth bot operations and troubleshoot errors.

We do not sell, rent, or trade user data to third parties, advertising networks, or data brokers.

## 3. Data Storage & Security
All stored data is kept secure and accessed only as required by the Bot's core services. 

## 4. Data Deletion Requests
Users and server administrators have full control over their data:
* **Server Removal:** Removing the Bot from a server stops all further data collection for that server.
* **Manual Deletion:** You may request complete deletion of your user or server data at any time by contacting us on our Discord support server.

## 5. Contact
For any questions or data removal requests regarding this Privacy Policy, please reach out through our official Discord support server.
